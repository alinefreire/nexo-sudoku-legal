Esta Política de Privacidade descreve como Aline Freire coleta, usa e protege suas informações ao utilizar o aplicativo NEXO Sudoku.

1. Dados Coletados

O NEXO Sudoku é projetado para operar com o máximo de privacidade. Os seguintes dados são mantidos localmente no seu dispositivo:

  • Progresso do jogo, configurações e preferências (armazenamento local).
  • Telemetria de Insights (estatísticas de treino mantidas localmente).
  • Status de compra da versão Premium (armazenamento local via lojas de aplicativos).

Utilizamos serviços de terceiros que podem coletar dados para seu funcionamento:

  • Google Mobile Ads (AdMob): Usado para exibir anúncios em troca de recompensas. Pode coletar identificadores de dispositivo e dados de uso de rede para personalizar e rastrear anúncios, respeitando suas configurações de consentimento (UMP).
  • Google Play Billing: Usado para processar compras no aplicativo (IAP).
  • Firebase Analytics (Google): Pode coletar dados de uso do aplicativo e diagnósticos via Google, para nos ajudar a entender estabilidade e funis de jogabilidade (sem contas de usuário nossas).

Não possuímos servidores próprios para armazenamento de contas de usuário ou dados de gameplay.

2. Finalidade dos Dados

Os dados locais servem exclusivamente para garantir o funcionamento do jogo (salvar progresso e exibir estatísticas do jogador). Os dados coletados por terceiros servem para viabilizar anúncios e compras.

3. Retenção e Exclusão de Dados

Como os dados do jogo são salvos no próprio dispositivo, eles são retidos até que você limpe os dados do aplicativo nas configurações do sistema ou desinstale o NEXO Sudoku. Ao fazer isso, todos os dados locais serão permanentemente apagados.

4. Direitos do Usuário

Você tem controle sobre os dados locais, podendo apagá-los a qualquer momento desinstalando o app ou limpando os dados nas configurações do sistema. As preferências de anúncios (consentimento UMP) podem ser geridas pelas configurações de privacidade/anúncios do dispositivo e pelo formulário de consentimento quando o app o apresentar.

5. Contato

Em caso de dúvidas sobre privacidade, entre em contato através do e-mail: linefreire2312@gmail.com

This Privacy Policy describes how Aline Freire collects, uses, and protects your information when you use the NEXO Sudoku app.

1. Data Collected

NEXO Sudoku is designed to operate with maximum privacy. The following data is kept locally on your device:

  • Game progress, settings, and preferences (local storage).
  • Insights telemetry (training statistics kept locally).
  • Premium version purchase status (local storage via app stores).

We use third-party services that may collect data for their operations:

  • Google Mobile Ads (AdMob): Used to display rewarded ads. It may collect device identifiers and network usage data to personalize and track ads, respecting your consent settings (UMP).
  • Google Play Billing: Used to process in-app purchases (IAP).
  • Firebase Analytics (Google): May collect app usage and diagnostics via Google to help us understand stability and gameplay funnels (we do not run our own user accounts).

We do not own servers to store user accounts or gameplay data.

2. Purpose of Data

Local data is used exclusively to ensure the game functions (saving progress and displaying player statistics). Data collected by third parties is used to enable ads and purchases.

3. Data Retention and Deletion

Because game data is saved on the device itself, it is retained until you clear the app's data in the system settings or uninstall NEXO Sudoku. Doing so will permanently delete all local data.

4. User Rights

You have control over your local data and can delete it at any time by uninstalling the app or clearing the app data in system settings. Ad preferences (UMP consent) can be managed via the device’s privacy/ad settings and via the consent form when the app presents it.

5. Contact

If you have any questions regarding privacy, please contact us at: linefreire2312@gmail.com
